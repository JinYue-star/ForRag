# Global KB (default) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make KB notes/attachments globally shared across all chat sessions, while keeping chat-uploaded files session-scoped and deletable with session deletion.

**Architecture:** Introduce a fixed global `kb_id="default"` used by all KB read/write and indexing. Migrate existing KB rows and KB files from per-session storage (`.uploads/<sid>/kb/...`) into global storage (`.uploads/kb/default/...`). Keep session file upload paths and Chroma session file list unchanged.

**Tech Stack:** FastAPI, SQLite (kb.sqlite), local filesystem, Chroma (session file metadata), existing RAG pipeline.
