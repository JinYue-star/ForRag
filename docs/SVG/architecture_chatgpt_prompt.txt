## Layer specification (must include all; layout may flex, meaning must not)

### 第 1 层 · 前端交互层
- 登录 / 教师台: 师生角色入口; 账号登录与注册; 用户与注册码管理
- AI 助手 [主链路]: 个人会话（他人不可见）; 上传临时材料并提问; 回答带出处引用
- 课程知识库: 分类与笔记管理; 上传课程材料; 发布课堂练习
- 测验 / 导出: 在线作答与批改; 导出提问与成绩; 不导出对话正文

### 第 2 层 · 接口服务层
- 身份与管理: 登录注册鉴权; 教师管理用户; 注册码查看与轮换
- 会话与文件 [主链路]: 创建与管理会话; 上传 / 删除附件; 聊天消息存取
- 知识库与问答: 知识库读写接口; 同步 / 异步问答; 可选检索范围
- 测验与导出: 生成与批改测验; 课堂练习发布; 成绩 / 提问导出

### 第 3 层 · 核心业务层
- 问答编排 [主链路]: 汇总可用材料; 调度检索与生成; 控制并发与任务
- 文档处理: 解析课件与附件; 智能切分文本; 建立向量索引
- 检索增强: 语义 + 关键词检索; 结果融合与重排; 必要时自动再查
- 生成与练习: 依据材料生成回答; 引用与质量门控; 出题、批改、导出

### 第 4 层 · 数据与存储层
- 会话数据库: 会话与聊天记录; 测验题目与结果; 不存文档向量
- 业务数据库: 用户与登录令牌; 知识库分类与笔记; 课堂练习清单
- 文件存储: 会话临时附件; 课程原始材料; 笔记相关文件
- 向量索引 [主链路]: 课程内容向量化; 支撑语义检索; 随材料更新重建

### 第 5 层 · 模型与外部能力
- 文本嵌入 [主链路]: 把材料变成向量; 支持中英双语; 本地运行
- 结果重排: 精排检索片段; 提高相关度; 本地运行
- 大语言模型: 生成回答与讲解; 改写问题 / 出题; 云端 API 调用
- 部署约束: 单机单进程服务; 浏览器直接访问; 前端不直连数据库

### 第 6 层 · 主流程
步骤: 上传课程材料 → 解析并建索引 → 智能检索相关内容 → 大模型生成回答 → 保存回答与引用 → 生成测验练习 → 批改并导出成绩
